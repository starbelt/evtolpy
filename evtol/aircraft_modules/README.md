# Aircraft modules

This directory includes modules related to aicraft simulation

## Directory Contents

* [__init__.py](__init__.py): The evtolpy aircraft modules package initialization file
* [aircraft_abu.py](aircraft_abu.py): ABU module for aircraft model
* [aircraft_aero.py](aircraft_aero.py): Aerodynamic module for aircraft model
* [aircraft_battery.py](aircraft_battery.py): Battery module for aircraft model
* [aircraft_geometry.py](aircraft_geometry.py): Aircraft geometry module for aircraft model
* [aircraft_iteration.py](aircraft_iteration.py): Weight iteration module for aircraft model
* [aircraft_mass.py](aircraft_mass.py): Mass/Weight module for aircraft model
* [aircraft_performance.py](aircraft_performance.py): Flight performance module for aircraft model
* [aircraft_propulsion.py](aircraft_propulsion.py): Propulsion module for aircraft model
* [README.md](README.md): This document
